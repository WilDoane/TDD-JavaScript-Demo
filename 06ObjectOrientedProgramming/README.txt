TASK OVERVIEW
==============

In this task, you'll create an object and assign properties to it.  

The object will have attributes defined to it.

If your object is defined as door and you want to define what door is made of:

		door.material = "wood";
		
In defining properties of objects in one location, if a property changes, you would be able to change the property in the entire document (where it would be called door.material) without having to go through and change it manually; you need only change it in one place.
